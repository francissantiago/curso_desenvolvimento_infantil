1 / 8

Classes x IDs

  • Classe (.botao-verde): pode ser usada em vários elementos.
  • ID (#cabecalho): só deve aparecer uma vez na página.
  • Use classes para estilos repetidos e IDs para itens únicos.

🤔 Pergunta

Qual parte do seu site precisa de um ID único? E qual parte pode compartilhar o mesmo estilo?

2 / 8

Exemplo: marcando com classe e ID

Observe como usamos a classe .card em vários elementos e o ID #heroi-do-dia em apenas um.

<div class="card destaque">
<div id="heroi-do-dia"> ... </div>
</div>
3 / 8

CSS Direcionado

.card {
    border-radius: 12px;
    padding: 16px;
}
.destaque {
    border: 2px dashed #f6ad55;
}
#heroi-do-dia {
    background: #fff4e6;
    box-shadow: 0 6px 20px rgba(0,0,0,0.15);
}

🧠 Desafio

Crie uma classe nova para o botão do seu site e um ID para o cabeçalho principal.

4 / 8

Montando o cartão no HTML

Nosso cartão terá uma classe geral e um ID exclusivo.

<div class="card personagem" id="heroi-do-dia">
    <img class="card-foto" src="URL" alt="Personagem">
    <h2 class="card-nome">Nome</h2>
    <p class="card-descricao">Frase marcante</p>
</div>

Estilizando o cartão com CSS

.card {
  width: 240px;
  padding: 18px;
  border-radius: 16px;
  text-align: center;
  background: #f0f4ff;
}
.card-foto { border-radius: 12px; }
#heroi-do-dia {
  border: 3px solid #7f9cf5;
  box-shadow: 0 10px 25px rgba(0,0,0,0.1);
}
