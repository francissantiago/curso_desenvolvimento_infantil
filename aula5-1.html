👩‍💻 Revisão: HTML Básico

Da Aula 2: HTML é a estrutura da página, como ossos de um corpo!

  • <html>, <head>, <body> - Estrutura básica
  • <h1> a <h6> - Títulos
  • <p> - Parágrafos
  • <img> - Imagens
  • <a> - Links
<h1>Meu Título</h1>
<p>Meu parágrafo.</p>
<img src="imagem.jpg" alt="Descrição">

🎨 Exercício:

Escreva uma tag HTML para um título e um parágrafo sobre você!

🎨 Revisão: CSS para Estilo

Da Aula 4: CSS deixa tudo bonito, como roupas coloridas!

  • color: Muda cor do texto
  • background-color: Fundo colorido
  • font-family: Tipo da letra
  • font-size: Tamanho da fonte
body {
  background-color: lightblue;
}
h1 {
  color: darkblue;
  font-family: 'Comic Sans MS';
}

🎨 Exercício:

Escreva CSS para deixar um título vermelho e o fundo amarelo!

4 / 10

📦 Revisão: Layout e Caixas

Da Aula 5: Use <div> para organizar como caixas!

  • <div> - Container para agrupar elementos
  • width, height: Tamanho da caixa
  • border: Borda da caixa
  • padding, margin: Espaçamento
.minha-caixa {
  width: 200px;
  height: 100px;
  background-color: pink;
  border: 2px solid red;
  padding: 10px;
}

📦 Exercício:

Crie uma caixa azul com borda preta usando CSS!
